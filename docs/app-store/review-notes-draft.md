# Finova App Review notes draft

Finova requires no account and no reviewer credentials. All core features run offline with local data.

Suggested synthetic review flow:

1. Open Finova. The ledger is empty by default.
2. Tap the add button and create an expense for `$42.15`, description `Synthetic market purchase`, date today, category Groceries.
3. Open Budgets, set Groceries to `$100.00`, and observe the numeric/text progress state.
4. Return Home and open the six-month view. It summarizes only local entries and clearly states that it is not a forecast or recommendation.
5. Open Settings. JSON and CSV export open the system share sheet only after a tap. Closing the sheet is not treated as proof of delivery.
6. Import validates a versioned JSON file before showing a destructive replacement confirmation.
7. Type the exact phrase `DELETE` and tap Delete All Data. The active ledger, budgets, and Finova-owned temporary artifacts are cleared.

No bank, payment, account, AI, analytics, tracking, notification, subscription, or advice feature is present. Device-backup restoration remains disclosed in the app and privacy policy.
